# 1.3.0 图片缩略图

验收：每张可预览图片在文件名前显示40×40区域内的等比缩略图，列表滚动和批量标签处理保持可用；失败仅影响预览，不改变标签处理结果。

- 行高56，保留文件名、类型、状态、文件夹四列及原有排序/选择/详情交互。
- 仅可见行请求预览；最多32个待加载任务、256张内存缓存。缓存被淘汰后，再次滚入可重新加载。
- 独立隐藏的 Windows PowerShell 5.1 进程读取源文件；源流使用共享读写/删除方式，读成内存快照后立即关闭，再解码。PNG/JPEG/TIFF 通过GDI，其他格式可尝试系统Shell解码器；Shell仅访问本地临时快照。WebP是否可预览取决于已安装解码器。视频显示占位图。
- 每张预览8秒超时，终止并重新创建加载进程。所有格式超过64MB不生成预览；GDI可读取源尺寸时，超过6000万像素拒绝。Shell回退只能取得缩略图，无法判断原图像素数，使用同一输入大小和独立进程超时限制。损坏/解码失败显示占位图，运行时失败记录WARNING日志并在悬停提示中说明。
- 批量操作开始前先暂停并终止预览进程，确认退出后才进入文件处理；无法确认退出则不启动批次。处理完成恢复加载。清空/关闭时释放图片及工作进程。
- 缩略图不写回源图片，不持久保存预览缓存。系统解码需要的本地临时文件仅存在于独立的 `%LOCALAPPDATA%\SynthTag\ThumbnailWork\<GUID>`，退出时清理自己的目录；强制结束整个应用可能留下该临时目录。

验证包含真实彩色PNG/JPEG/TIFF、方向/比例、中文方括号路径、坏图后继续、独占打开源文件、源SHA-256不变、屏外延迟加载、暂停/恢复、超时和关闭、260张缓存压力，以及标签写入和单文件包回归。美工现场远程SMB问题仍未复现，既有安全写入和诊断流程保留。

2026-10-17，Windows PowerShell 5.1 实测通过：缩略图worker协议与可见列表测试、260张缓存压力测试、19项文件处理回归、日志/诊断回归、原有UI交互、22项启动/打包测试。以真实子进程持有源句柄验证暂停在2秒内释放；不响应请求8秒后被终止，随后健康图片可继续预览。最终517条打包文件与源码全字节一致，隔离提取后运行 `app.ps1 -NoUI` 成功。代码审查发现的刷新旧缓存及提示覆盖标签错误均已修复并复验。
