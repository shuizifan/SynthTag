# SynthTag 1.2.0 界面改进与验收

目标：界面简洁，添加、处理、查看结果的顺序清晰；用户无需悬停即可看到异常原因。继续使用Windows自带PowerShell 5.1和WinForms，不增加安装依赖。

## 变更

- 浅色背景、白色列表、蓝色主按钮、文字状态徽标、统一间距和按钮焦点反馈；去掉文件名删除线。
- 添加文件/文件夹/粘贴路径为入口；开始添加为唯一主要操作；检查、移除、导出为次要操作。
- 全部、待添加、已有标签、需关注四项计数。重复标签可同时计入待添加和需关注；警告可同时属于已有标签或已移除，因此这些计数不要求相加等于总数。
- 详情区显示完整路径和错误/警告，支持选择复制；取消选择、多选、排序后刷新，避免显示上一文件内容。
- 空列表引导；处理时显示进度和文件数；无可执行对象的按钮禁用。
- 新添加文件追加，保留前一批结果和异常记录；清空及移出仅影响列表。
- 警告保留真实操作结果：“已移除·有警告”仍可再次添加；状态逻辑不依赖界面文案。
- 设置页分为本地日志和问题排查，保留30天、日志健康状态、打开目录和诊断包隐私说明。

文件处理与诊断引擎保持1.1.0实现。既有19项元数据回归、日志/诊断回归及更新后的16项缓存/提取和4项打包回归已重新执行并通过。实际远程共享故障仍遵循[既有排查记录](shared-folder-investigation.md)的验证边界。
